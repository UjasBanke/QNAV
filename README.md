# QNAV — NV-Center Ensemble Quantum Navigation Console

An interactive Next.js-based quantum navigation console for exploring
NV-center sensor ensembles, geomagnetic navigation, receiver positioning,
trajectory simulation, and ML-based position estimation.

The application provides a complete browser-based visualization platform
with a responsive navigation shell, interactive 3D sensor geometry,
real-world geographic mapping, route simulation, sensor analysis,
position estimation, and data export.

The ML model training is maintained separately in the
`NV_ML` repository. This website uses the generated ML results for
interactive visualization and simulation.

## Modules

### Mission Control

Provides the main navigation dashboard and system status.

Includes:

- Navigation system status
- Live simulation status
- Sensor/sample information
- Quick access to major modules

### Vehicle & Motion

Allows the user to configure the simulated receiver/vehicle.

Supported vehicle types:

- Ground
- Aircraft
- Drone
- Ship

Vehicle parameters include:

- Speed
- Altitude
- Climb rate
- Motion constraints

Ground vehicles automatically enforce the appropriate altitude and
climb-rate restrictions.

### Location & Route

Interactive world map using real geographic country boundaries.

Features:

- Click on the map to place waypoints
- Multiple waypoint support
- Direct latitude/longitude editing
- Route generation
- World-to-route animated zoom
- Real geographic trajectory visualization

The map uses geographic GeoJSON data rather than a stylized map.

### Sensor Ensemble

Interactive 3D visualization of the NV-center sensor ensemble.

Features:

- 3D diamond-axis visualization
- Drag-to-rotate interaction
- Automatic rotation
- Configurable diamond count
- Sensor geometry visualization
- NV sensor noise information
- Live simulation parameters

The sensor ensemble is used to demonstrate how multiple NV-center
orientations can contribute to magnetic-field reconstruction.

### Analysis

Provides visualization of the simulated magnetic-field reconstruction.

Current charts include:

1. Magnetic-field reconstruction vs ground truth
2. Reconstruction error vs time

The reconstruction chart automatically scales its Y-axis according to
the generated data instead of using a fixed misleading range.

### Position Estimation

Interactive ML-based receiver positioning module.

The website visualizes results generated by the separate `NV_ML`
Python repository.

Current model:

- XGBoost regression

The model predicts:

- Latitude
- Longitude
- Altitude

The module includes:

- ML processing pipeline visualization
- Actual vs predicted position
- Interactive 3D receiver trajectory
- Actual trajectory
- Predicted trajectory
- Current position markers
- Current 3D position error
- Interactive time slider
- Play/pause simulation
- Reset simulation
- Latitude comparison
- Longitude comparison
- Altitude comparison
- 3D position error vs time
- Latitude error
- Longitude error
- Altitude error
- Feature importance
- MAE
- MSE
- RMSE
- R²

The 3D position error is calculated as the Euclidean distance between
the actual and predicted receiver positions after converting the
geographic coordinates into a local metric coordinate system.

Conceptually:

    E3D = sqrt(Ex² + Ey² + Ez²)

where:

- Ex = east/west position error
- Ey = altitude error
- Ez = north/south position error

The displayed 3D error is expressed in metres.

## ML Data Used by the Website

Generated ML results are stored under:

    public/data/ml/

Current files:

    public/data/ml/
    ├── 3d_position_error.json
    ├── feature_importance.json
    ├── metrics.json
    └── trajectory.json

### `trajectory.json`

Contains the time-dependent actual and predicted receiver positions.

Typical fields include:

- Time
- Actual latitude
- Actual longitude
- Actual altitude
- Predicted latitude
- Predicted longitude
- Predicted altitude

### `3d_position_error.json`

Contains the calculated position error for each sample.

Includes:

- Time
- Latitude error
- Longitude error
- Altitude error
- 3D position error

### `feature_importance.json`

Contains the feature importance values obtained from the XGBoost model.

### `metrics.json`

Contains model evaluation metrics calculated from the held-out test
data.

## 3D Position Visualization

The Position Estimation module converts geographic coordinates into a
local Cartesian coordinate system for visualization.

The coordinate convention is:

- X → East
- Y → Up / altitude
- Z → North/South

The conversion allows the receiver trajectory to be displayed in a
3D scene while preserving the relative geographic geometry.

The visualization contains:

- Actual trajectory
- Predicted trajectory
- Current actual position
- Current predicted position
- Error connector between the two positions

The visualization scaling is applied only for displaying the trajectory
inside the 3D scene. The calculated position errors remain in metres.

## Simulation

The website provides an interactive time-based simulation.

The user can:

- Drag the simulation slider
- Select any point in the trajectory
- Play the simulation
- Pause the simulation
- Reset the simulation

Changing the simulation time updates:

- Current actual position
- Current predicted position
- Latitude
- Longitude
- Altitude
- Individual position errors
- 3D position error
- Current position markers
- Error indicator
